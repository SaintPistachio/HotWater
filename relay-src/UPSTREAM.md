# Bundled relay source

The relay runtime is based on [ha-icomm-local](https://github.com/ericboehs/ha-icomm-local) at commit 2507eb2e6c30f9f1f06f15051f3750b11aaa9828. The local changes add the owner-only HotWater command endpoints for the supported heater. The upstream MIT license is in this directory.
